## 📖 游戏简介

费兰德世界是一个基于 Vue3 + Node.js 的挂机文字成长游戏。角色自动在区域中战斗、升级、获取装备，玩家通过分配属性、选择职业、搭配词条、附魔装备来构建独特 Build，最终目标是从凡人进化为天使、领悟法则、登神成神。

### 🎮 核心玩法循环

```
挂机打怪 → 获取经验/金币/装备 → 升级分配属性 → 选择职业路线
    ↑                                                    ↓
    ← ← ← 搭配词条/附魔/进化 ← 切换更高区域 ← 解锁新系统 ←
```

## 🚀 快速开始

### 环境要求

- **Node.js** >= 18
- **pnpm**（推荐）或 npm

### 方法一：一键启动（Windows）

双击 `启动游戏.bat` 文件即可。

### 方法二：命令行启动

```bash
# 安装依赖
pnpm install

# 启动开发服务器（前后端同时运行）
pnpm dev
```

然后在浏览器打开 **http://localhost:3000**

### 方法三：分别启动前后端

```bash
# 终端 1：启动后端
pnpm dev:server

# 终端 2：启动前端
pnpm dev:client
```

- 前端：http://localhost:3000
- 后端 API：http://localhost:3001

### 生产构建

```bash
pnpm build      # 构建前端到 client/dist/
```

### 端口配置

本项目默认使用两个端口：

| 服务 | 默认端口 | 配置文件 | 修改位置 |
|------|----------|----------|----------|
| 前端 (Vite) | 3000 | `vite.config.js` | `server.port: 3000` |
| 后端 (Express) | 3001 | `server/index.js` | `const PORT = 3001` |

**修改前端端口**：编辑 `vite.config.js`

```js
// vite.config.js
server: {
  port: 8080,  // ← 改成你想要的端口
  proxy: {
    '/api': 'http://localhost:3001'  // ← 指向后端端口
  }
}
```

**修改后端端口**：编辑 `server/index.js`

```js
// server/index.js
const PORT = 3002;  // ← 改成你想要的端口
```

> **注意**：修改后端端口后，务必同步修改 `vite.config.js` 中 proxy 的 `/api` 目标地址，否则前端无法请求后端 API。

## 🎯 新手指南

1. **注册/登录** — 输入账号密码即可（同名继续之前的进度）
2. **自动挂机** — 角色自动在当前区域战斗，获取经验和金币
3. **升级分配** — 升级后获得属性点，点击 `+` 分配到 ATK/DEF/HP/AGI
4. **选择职业** — Lv.11 后在「角色」页选择 5 大职业之一
5. **搭配词条** — 在「技能」页装备主动/被动词条
6. **装备附魔** — 在「背包」页点击装备查看详情，消耗材料附魔
7. **切换区域** — 达到等级要求后切换到更高级区域
8. **种族进化** — Lv.30 收集材料进化为翼人，Lv.80 进化为天使
9. **领悟法则** — Lv.100+ 在深渊裂隙收集法则碎片，学习法则
10. **登神** — 满足条件后登神，从半神到神灵

## 🎨 UI/UX 设计规范

本项目遵循统一的交互设计规范：

| 场景 | 交互形式 | 原因 |
|------|----------|------|
| 背包、技能、图鉴、地图 | **全屏替换**（左右滑动） | 内容量大，需要沉浸式浏览 |
| 装备详情、词条详情 | **居中弹窗**（Modal） | 临时操作，看完关掉回到原页面 |
| 商店购买 | **底部弹出**（Action Sheet） | 即时反馈，带操作按钮 |

**底部导航栏**：固定 5 个 Tab，不再新增。中间第 3 个为「地图」按钮，圆形凸起高于其他 4 个。后续新增功能页面按关联性嵌入对应页面的右侧折叠面板（小箭头点击展开/收起），不占用底部 TabBar。例如进阶/任务嵌入角色页、排行嵌入地图页。

**页面切换动画**：基于 Tab 顺序的智能滑动方向（右滑进入 / 左滑返回）

**网格布局**：4 列网格 + 分页器，每页 12 项，点击格子弹出详情弹窗
