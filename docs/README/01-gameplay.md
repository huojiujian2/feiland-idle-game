# 游戏玩法

> 📖 主入口：[../README.md](../README.md)

## 核心玩法循环

```
挂机打怪 → 升级分配 → 选职业路线 → 装备附魔/锻造/合成
    ↑                                           ↓
    ← ← ← 转生轮回（永久加成）← 登神成神 ← 种族进化
                                              ↓
                                         世界 BOSS / PVP
```

## 五大职业系

| 职业系 | 图标 | 特色 | 4 阶成长路线 |
|--------|------|------|-------------|
| ⚡ 雷霆系 | bolt | 高爆发高机动，暴击流 | 御雷者 → 雷霆之翼 → 圣翼行者 → 圣雷之炽 |
| ✨ 光明系 | sparkle | 攻防一体，附带治愈 | 光明剑士 → 圣光骑士 → 光翼审判者 → 炽天使 |
| 🌪 风行系 | sparkle | 速度极快，闪避游击 | 信使 → 风之使者 → 风行者 → 风暴领主 |
| 🛡 骑士系 | shield | 骑乘战斗，坦克型 | 见习骑士 → 天空骑士 → 龙骑士 → 血骑士 |
| ⚗ 炼金系 | scroll | 生产辅助，金币流 | 学徒 → 炼金师 → 附魔师 → 大炼金术士 |

每个职业拥有：
- **2 个专属天赋**（被动加成）
- **4 级成长机制**（Lv.1/2/3/4 逐级解锁）
- **独立成长系数**（HP/ATK/DEF/AGI/EXP/GOLD 增长率不同）

## 新手指南

1. **注册/登录** — 输入账号密码即可（同名继续之前的进度）
2. **自动挂机** — 角色自动在当前区域战斗，获取经验和金币
3. **升级分配** — 升级后获得属性点，点击 `+` 分配到 ATK/DEF/HP/AGI
4. **选择职业** — Lv.11 后在「角色」页选择 5 大职业之一
5. **搭配词条** — 在「技能」页装备主动/被动词条
6. **锻造装备** — 在「背包」页升级 +1~+10 / 合成 3 合 1 / 重铸词条
7. **切换区域** — 达到等级要求后切换到更高级区域（Lv.250 创世核心是终极目标）
8. **种族进化** — Lv.30 收集材料进化为翼人，Lv.80 进化为天使
9. **领悟法则** — Lv.100+ 在深渊裂隙收集法则碎片
10. **登神** — 半神 → 神灵
11. **转生轮回** — Lv.100+ 通关龙岛后开启，每次轮回永久累积加成
12. **挑战世界 BOSS** — 地图侧边抽屉，每 30 分钟刷一只

## 词条系统详解

```
┌─────────────────────────────────────────────────┐
│                 词条槽位配置                       │
├─────────────────────────────────────────────────┤
│  主动词条槽 ×1    →  选择 1 个 主动技能            │
│  被动词条槽 ×1~5  →  随职业阶段解锁更多槽位       │
│                                                   │
│  0阶 = 1 被动槽                                   │
│  1阶 = 2 被动槽                                   │
│  2阶 = 3 被动槽                                   │
│  3阶 = 4 被动槽                                   │
│  4阶 = 5 被动槽                                   │
└─────────────────────────────────────────────────┘
```

| 词条等级 | 图标 | 解锁等级 | 数量 | 示例 |
|----------|------|----------|------|------|
| 🔰 初级 | star | Lv.1 | 50 | 雷霆冲击、力量祝福、自愈 |
| ⚙️ 中级 | plus | Lv.31 | 50 | 雷暴术、护甲祝福 II、吸血 |
| 🔥 高级 | sparkle | Lv.61 | 50 | 圣雷降临、炽天使之焰 |
| 💎 大师 | gem | Lv.100 | 50 | 天罚、虚空领域 |

> **200 个词条** × **5 大职业** × **多种附魔搭配** = 几乎无限的 Build 可能性
